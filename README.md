# CargoWise eAdaptor Interface

This is a simple package to facilitate communication with the CargoWise eAdaptor.
It contains interfaces for both the CargoWise eAdaptor Classic and Next versions.

You can find this package on the [NuGet Package Manager](https://www.nuget.org/packages/CargoWiseEAdaptorInterface/).
